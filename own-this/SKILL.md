# Own this

1. Treat the whole preceding brief and later user decisions as the assignment. Identify its deliverables, constraints, approval boundaries, and what the user must be able to do when the work is ready.
2. Delegate independent deliverables with a clear scope and completion check. Give each assignee the relevant decisions, dependencies, and evidence needed for their part. Keep tightly coupled work with the main agent. The main thread owns tradeoffs across assignments.
3. Monitor the assignments through completion notifications. Work on remaining dependencies or integration while agents run. Intervene when a blocker, new decision, or conflicting change affects an assignment.
4. Compare returned work with the brief. Give the assignee concrete feedback: the unmet criterion, what you observed, and the result needed. Verify the correction in the combined deliverable. Use up to five feedback rounds across the assignment, starting with the first assessment of returned work. Stop early once the criteria pass.
5. Personally exercise the user's entry point through the requested outcome, including sign-in when relevant. For timing or responsiveness, capture an interaction or measure the delay. Report the evidence, where user-only access limited the check, and any unresolved criteria at the round limit. A formal code review or bug-fix loop is a separate task when requested.
