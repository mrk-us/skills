# Data and performance

| Task | Library |
| --- | --- |
| Data fetching | [TanStack Query](https://tanstack.com/query/latest) |
| Forms | [TanStack Form](https://tanstack.com/form/latest) |
| Throttling, debouncing, or rate limiting | [TanStack Pacer](https://tanstack.com/pacer/latest) |
| Virtualization for long lists or large tables | [TanStack Virtual](https://tanstack.com/virtual/latest) |

For frontend data fetching, reuse the project's TanStack Query setup. If the project has no data-fetching library, choose TanStack Query.
