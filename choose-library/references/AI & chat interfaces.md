# AI & chat interfaces

For basic interfaces, shadcn provides [message scroller](https://ui.shadcn.com/docs/react/message-scroller) and [questionnaire](https://ui.shadcn.com/docs/react/questionnaire) components, plus helpers for the [AI SDK](https://ui.shadcn.com/docs/helpers/ai-sdk) and [TanStack AI](https://ui.shadcn.com/docs/helpers/tanstack-ai).

Choose between [TanStack AI](https://tanstack.com/ai/latest) and [Vercel AI SDK](https://ai-sdk.dev/docs/introduction) based on the use case and existing stack.

For more elaborate agent interfaces, reach for these in order of component needs:

| Task | Library |
| --- | --- |
| AI components | [BeautifulUI](https://www.beautifului.dev/) |
| Agent harness | [Ice Cream Harness](https://www.beautifului.dev/harness) |
| Additional agent components | [beUI](https://beui.dev/components/agents) |
