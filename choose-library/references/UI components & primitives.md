# UI components & primitives

When shadcn is already configured, use its components and install them with `bunx shadcn@latest add {component}`.

Else, use these primitives:

| Task | Library |
| --- | --- |
| Unstyled, accessible dialogs, popovers, menus, or selects | [Base UI](https://base-ui.com) |
| Command menus and Command-K palettes | [cmdk](https://cmdk.paco.me) |
| Toasts and notifications | [Sonner](https://sonner.emilkowal.ski) |
| One-time password and verification code inputs | [input-otp](https://input-otp.rodz.dev) |
| Tables | [TanStack Table](https://tanstack.com/table/latest) |
| Hotkeys and keyboard shortcuts | [TanStack Hotkeys](https://tanstack.com/hotkeys/latest) |
| Markdown | [TanStack Markdown](https://tanstack.com/markdown/latest) or [remark and react-markdown](https://remarkjs.github.io/react-markdown/) |

Use Dialkit whenever the user asks for debug controls:

| Task | Library |
| --- | --- |
| Customizable GUIs and control panels | [DialKit](https://joshpuckett.me/dialkit) |
