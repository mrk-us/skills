# Motion, transitions, animations

| Task | Library or source |
| --- | --- |
| Springs, layout animation, enter and exit animation, or gesture-driven values | [Motion](https://motion.dev) |
| GPU-accelerated text shimmer | [Components reference](~/Dev/components-reference) |
| Fade-in-up or staggered card entrances | [Components reference](~/Dev/components-reference) |
| Loading states and spinners | [Components reference](~/Dev/components-reference) |
| Animated counters, prices, or statistics | [NumberFlow](https://number-flow.barvian.me) |
| Animated text components | [Animate text](https://pixelpoint.io/skills/animate-text/) or [torph](https://torph.lochie.me/) |
| 3D globes | [Cobe](https://cobe.vercel.app) |
| Dynamic OG images from HTML and CSS | [Satori](https://github.com/vercel/satori) |
| Syntax highlighting | [Shiki](https://shiki.style) |

Use Motion for springs, layout animation, exit animation, or gesture-driven values. Use CSS transitions for a simple hover or fade.

For a loading state, reuse the project's existing spinner when it follows this choice. If none exists, use the Spinner from the Components reference.
